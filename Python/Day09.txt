DAY 09 - SETS & DICTIONARIES


1. SET
.A set is an unordered, mutable collection used to store unique values.
.Sets are created using set() function.
.Duplicates are automatically removed.

Example:
numbers = {10, 20, 30}
names = {"Ravi", "Teja", "Ankit"}
mixed = {10, "Python", 5.5, True}

Set Properties:
- Unordered
- Mutable
- Unindexed
- Iterable
- Unique elements
- Heterogeneous
- Dynamic size
- Can contain immutable objects like tuples and frozensets
- Lists, sets and dictionaries cannot be stored directly


2. CREATING SETS

Empty Set:
s = set()

Set with duplicate values:
data = {10, 20, 30, 20, 10}
print(data)

Output:
{10, 20, 30}

#Duplicates are removed automatically.


3. SET OPERATIONS

1. Membership Operators

Checks whether an element exists.

data = {10, 20, 30}

print(20 in data)
# True

print(100 not in data)
# True


2. Union

Combines all unique elements from both sets.

a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)

Output:
{1, 2, 3, 4, 5}


3. Intersection

Returns common elements.

a = {1, 2, 3}
b = {2, 3, 4}

print(a & b)

Output:
{2, 3}


4. Difference

Returns elements present in the first set but not the second.

a = {1, 2, 3}
b = {2, 3, 4}

print(a - b)

Output:
{1}


5. Symmetric Difference

Returns elements present in either set but not both.

a = {1, 2, 3}
b = {2, 3, 4}

print(a ^ b)

Output:
{1, 4}


6. Subset

Checks whether all elements of one set exist in another.

a = {1, 2}
b = {1, 2, 3, 4}

print(a <= b)

Output:
True


7. Superset

Checks whether a set contains all elements of another set.

a = {1, 2, 3, 4}
b = {1, 2}

print(a >= b)

Output:
True


4. BUILT-IN SET FUNCTIONS

len()     -> Returns number of elements
max()     -> Returns largest element
min()     -> Returns smallest element
sum()     -> Returns sum of numeric elements
sorted()  -> Returns sorted list
set()     -> Converts iterable to set
any()     -> Returns True if any element is True
all()     -> Returns True if all elements are True


5. SET METHODS

Adding Methods:

1.add():Adds one element.
Example:
s.add(10)

2.update():Adds multiple elements.
Example:
s.update([20, 30])

#Removing Methods:

1.remove():Removes element. Gives error if element is absent.
Example:
s.remove(10)

2.discard():Removes element. No error if element is absent.
Example:
s.discard(10)

3.pop():Removes a random element.
Example:
s.pop()

4.clear():Removes all elements.
Example:
s.clear()

#Copying Method:

1.copy():Creates a shallow copy.
Example:
s.copy()


Set Relation Methods:

1.union():Combines sets.
Example:
a.union(b)

2.intersection():Returns common elements.
Example:
a.intersection(b)

3.difference():Returns elements in first set only.
Example:
a.difference(b)

4.symmetric_difference():Returns non-common elements.
Example:
a.symmetric_difference(b)


#Subset & Superset Methods:

1.issubset():Checks subset.
Example:
a.issubset(b)

2.issuperset():Checks superset.
Example:
a.issuperset(b)

3.isdisjoint():Checks whether there are no common elements.
Example:
a.isdisjoint(b)

6. FROZENSET
.A frozenset is an immutable version of a set.
.Once created, elements cannot be added or removed.

Example:
data = frozenset({10, 20, 30})

Properties:
- Immutable
- Unordered
- Unique elements
- Hashable
- Can be used inside sets
- Can be used as dictionary keys


WHY USE SETS?

- Remove duplicate values
- Perform mathematical set operations
- Fast membership checking
- Store unique items
- Compare collections efficiently


7. DICTIONARY

A dictionary is a collection of key-value pairs used to store related data.

Dictionaries are created using curly braces {} or dict().

Example:
student = {
    "id": 101,
    "name": "Ravi",
    "course": "Python"
}


DICTIONARY PROPERTIES:

- Ordered
- Mutable
- Indexed by keys
- Iterable
- Keys must be unique
- Duplicate values are allowed
- Heterogeneous
- Dynamic size
- Nested structures supported
- Keys must be hashable


8. CREATING DICTIONARIES

Empty Dictionary:

data = {}

or

data = dict()


Dictionary with values:

student = {
    "id": 101,
    "name": "Ravi",
    "course": "Python"
}


Using dict():

student = dict(
    id=101,
    name="Ravi",
    course="Python"
)


9. DICTIONARY OPERATIONS

1. Accessing Values

Values are accessed using keys.

student = {
    "name": "Ravi",
    "age": 22
}

print(student["name"])
# Ravi

print(student["age"])
# 22


2. Updating Values

student = {
    "name": "Ravi",
    "age": 22
}

student["age"] = 23

print(student)


3. Adding New Key-Value Pairs

student = {"name": "Ravi"}

student["course"] = "Python"

print(student)


4. Removing Items

student = {
    "name": "Ravi",
    "age": 22
}

del student["age"]

print(student)


5. Membership Operators

Membership checks only keys.

student = {
    "name": "Ravi",
    "age": 22
}

print("name" in student)
# True

print("course" not in student)
# True


10. BUILT-IN DICTIONARY FUNCTIONS

len()     -> Returns number of key-value pairs
max()     -> Returns maximum key
min()     -> Returns minimum key
sorted()  -> Returns sorted list of keys
dict()    -> Creates dictionary
any()     -> Returns True if any key is True
all()     -> Returns True if all keys are True


11. DICTIONARY METHODS

Access Methods:

1.get():Returns value for a key.
Example:
d.get("name")

2.keys():Returns all keys.
Example:
d.keys()

3.values():Returns all values.
Example:
d.values()

4.items():Returns key-value pairs.
Example:
d.items()


#Adding & Updating Methods:

1.update():Updates dictionary.
Example:
d.update({"age": 25})

2.setdefault():Returns value and creates key if absent.
Example:
d.setdefault("city", "Hyd")

#Removing Methods:

1.pop():Removes specified key.
Example:
d.pop("age")

2.popitem():Removes last inserted item.
Example:
d.popitem()

3.clear():Removes all items.
Example:
d.clear()

#Copying Method:

1.copy():Creates a shallow copy.
Example:
d.copy()

#Creation Method:

1.fromkeys():Creates dictionary from keys.
Example:
dict.fromkeys(["a", "b"], 0)


12. NESTED DICTIONARIES

A dictionary inside another dictionary is called a nested dictionary.

Example:

students = {
    "s1": {"name": "Ravi", "age": 22},
    "s2": {"name": "Teja", "age": 21}
}

print(students["s1"]["name"])

Output:
Ravi


13. MUTABLE VALUES INSIDE DICTIONARIES

Dictionary values can be mutable objects.

Example:

student = {
    "marks": [90, 85, 88]
}

student["marks"].append(95)

print(student)

Output:
{'marks': [90, 85, 88, 95]}


14. VALID DICTIONARY KEYS

Dictionary keys must be immutable/hashable.

Valid keys can be:

101
3.14
True
"name"
(1, 2)

Example:

data = {
    101: "Ravi",
    3.14: "Pi",
    True: "Yes",
    "name": "Python",
    (1, 2): "Tuple Key"
}


WHY USE DICTIONARIES?

- Store related information together
- Fast data retrieval using keys
- Represent real-world objects
- Flexible data structures
- Commonly used in APIs, JSON, databases and applications


Example:

student = {
    "id": 101,
    "name": "Ravi",
    "course": "Python"
}

product = {
    "name": "Laptop",
    "price": 50000
}
